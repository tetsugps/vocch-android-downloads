# VOCCH Android

Google Play 未公開のAndroid版を、テスト用に配布しています。

## 最新版

- バージョン: 3.1.0 (version code 31)
- パッケージ: `jp.ti.vocch`
- [APKをダウンロード](https://github.com/tetsugps/vocch-android-downloads/releases/latest/download/app-release.apk)
- [リリース履歴とSHA-256](https://github.com/tetsugps/vocch-android-downloads/releases)

この版は、以前配布していた `com.vocch.client` とは別のアプリとして端末にインストールされます。既存版の更新にはなりません。

VOCCHには位置共有機能があります。同意して共有を開始すると、参加中の部屋の現在・今後のメンバーに位置が表示されます。共有中に後から部屋へ参加する人にも表示され、アプリを閉じた後も共有をOFFにするまで位置を取得・送信します。共有の範囲と停止方法をアプリ内で確認してください。

## 配布について

このAPKはGoogle Playを通さないテスト配布です。インストール時にAndroidが確認を表示することがあります。配布元とバージョンを確認し、信頼できる場合だけインストールしてください。

このリポジトリはダウンロード案内のみを公開し、アプリのソースコードは含みません。
