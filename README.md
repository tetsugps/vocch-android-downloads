# VOCCH Android APK

誰でもダウンロードできるVOCCH Android版の配布ページです。

## 最新版

- バージョン: 3.0.2 (version code 15)
- [app-release.apk をダウンロード](https://github.com/tetsugps/vocch-android-downloads/releases/latest/download/app-release.apk)
- [リリース履歴・SHA-256](https://github.com/tetsugps/vocch-android-downloads/releases)

このAPKはGoogle Playを通さない試用配布版です。インストール時にAndroidが確認を表示した場合、配布元とバージョンを確認してください。アプリは位置情報共有機能を含みます。共有を開始する前にアプリ内の共有設定と相手を確認してください。

このリポジトリはダウンロード用ファイルのみを公開し、アプリのソースコードは含みません。
